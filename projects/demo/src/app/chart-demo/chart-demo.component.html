Uso del componente ChartComponent

El componente ChartComponent (con selector de etiqueta <libChart>) se utiliza para incrustar y configurar gráficos. Requiere un objeto Dataset y un objeto ChartOptions como entradas. Adicionalmente, proporciona funcionalidades avanzadas como la gestión de líneas de meta (Goals) mediante el método toggleShowGoal().

Configuración de opciones del gráfico (ChartOptions)

TypeScript

Uso en el template HTML

HTML
<libChart
  [dataset]="dataset"
  [chartOptions]="chartOptions">
</libChart>

Panel de Configuración Interactiva

El componente ChartComponent incluye un panel de configuración integrado. Al pasar la propiedad de entrada [showEditor]="showBaseEditor" (o llamando al método público toggleEditor()), se mostrará u ocultará de forma dinámica el panel interactivo de configuración.

  • Edición en Vivo: Modifica títulos, tipos de gráficos, colores y leyendas en tiempo real.
  • Persistencia: Los cambios se emiten a través del evento (optionsChange).
  • Interfaz Intuitiva: El editor se muestra como un panel flotante que no interfiere con el diseño de la página.

2. Gráfico de Líneas con Series Múltiples

Esta configuración presenta un gráfico de líneas que muestra la evolución temporal de diferentes series de datos. El tooltip compartido permite comparar valores de múltiples series en un mismo punto temporal, mientras que las leyendas posicionadas a la derecha facilitan la identificación de cada línea. Este tipo de visualización es especialmente útil para análisis de tendencias y patrones temporales en datos continuos.

Este ejemplo avanzado muestra un gráfico de columnas apiladas que permite visualizar la composición total de cada categoría. Esta visualización es perfecta para mostrar partes de un todo y cómo cambian las proporciones a lo largo del tiempo.

5. Funcionalidades Interactivas

Esta sección demuestra las capacidades interactivas del componente ChartComponent. Incluye métodos para alternar entre vista normal y porcentual, así como opciones de exportación en formatos SVG y JPG. Los botones interactivos permiten cambiar dinámicamente el modo de visualización y descargar el gráfico en diferentes formatos, proporcionando flexibilidad para presentaciones y reportes.

TypeScript
HTML

6. Líneas de Meta (Goals)

Las líneas de meta permiten superponer objetivos o referencias visuales sobre el gráfico principal. Esta funcionalidad es especialmente útil para comparar el rendimiento actual contra objetivos establecidos. La interfaz Goal define el tipo de línea, texto descriptivo y datos de la meta. El método toggleShowGoal() permite mostrar u ocultar dinámicamente estas líneas de referencia sin regenerar todo el gráfico.
