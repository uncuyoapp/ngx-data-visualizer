Medidas y responsive para gráficos

Esta pantalla prueba la adaptación del motor de gráficos ante distintas dimensiones de contenedor y configuraciones de tamaño.

Caso 1 Tamaño Fijo por TypeScript

chartOptions = { width: 600, height: 400 }

Qué esperar: El gráfico debe medir exactamente 600x400 px y no encogerse aunque se reduzca la ventana (provocando scroll horizontal).

Caso 2 100% Responsivo en Contenedor Flexible

chartOptions = { width: null, height: null } dentro de un contenedor flexible.

Qué esperar: Arrastra la esquina inferior derecha del cuadro punteado. El gráfico debe redibujarse fluidamente para ocupar siempre el 100% del contenedor sin desbordes.

Caso 3 Variables CSS Inline

style="--viz-chart-height: 250px; --viz-chart-width: 80%;"

Qué esperar: El gráfico debe tener un alto estricto de 250px y un ancho que sea el 80% de la pantalla.

Caso 4 SCSS Externo

Clase CSS externa que aplica variables y flexbox al contenedor padre.

Qué esperar: El cuadro verde tiene 400px de alto. El gráfico debe ocupar ese 100% (400px verticales) y exactamente la mitad (50%) del ancho de la pantalla.
