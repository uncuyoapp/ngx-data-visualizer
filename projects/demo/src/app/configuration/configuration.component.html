Guía de configuración de ngx-data-visualizer

Esta sección explica cómo configurar e integrar la librería @uncuyoapp/ngx-data-visualizer dentro de una aplicación Angular. Abarca desde la instalación del paquete, la importación de módulos y componentes necesarios, hasta las configuraciones necesarias para utilizar los componentes disponibles. Si estás comenzando, este es el primer paso para incorporar nuestros componentes a tu proyecto.

Componentes disponibles

La librería proporciona los siguientes componentes standalone, que debes importar y usar según tus necesidades:

  • ChartComponent: para visualización de gráficos individuales, con selector de etiqueta o atributo libChart.
  • MultipleChartComponent: para visualizar múltiples gráficos simultáneamente, con selector de etiqueta o atributo libMultipleChart.
  • TableComponent: para mostrar datos en formato tabular, con selector de etiqueta o atributo libTable.

API de los Componentes

Nuestros componentes standalone están diseñados bajo una arquitectura robusta y reactiva, exponiendo entradas (Inputs), salidas (Outputs) y una API de métodos públicos interactivos. Para invocar métodos o suscribirte a eventos complejos, puedes usar el decorador ViewChild en tu componente padre.

Propiedades de Entrada (Inputs)

Input Tipo Por Defecto Descripción
[dataset] Dataset Requerido Instancia de la clase Dataset que provee las dimensiones, filtros y datos en bruto.
[(chartOptions)] / [(tableOptions)] ChartOptions | TableOptions Requerido Configuraciones visuales y de comportamiento específicas para cada gráfico o tabla. Soporta enlace bidireccional automático.
[(showEditor)] boolean false Controla y sincroniza de forma programática y bidireccional (two-way binding) la apertura y cierre del panel lateral de edición CDK Overlay.
[showLegends] Solo Gráficos boolean true Controla si se renderiza el componente de leyendas interactivas de series y años debajo o a los lados del gráfico.
[splitDimension] Solo Múltiples Gráficos Dimension Requerido Dimensión seleccionada para realizar la segmentación y renderizado de un gráfico por cada ítem marcado como activo.
[options] Solo Múltiples Gráficos ChartOptions Requerido Configuraciones visuales y de comportamiento específicas para el conjunto de gráficos segmentados.
[disableAutoUpdate] Solo Múltiples Gráficos boolean false Deshabilita la actualización automática de los gráficos segmentados ante cambios en el dataset.

Eventos de Salida (Outputs)

Output Tipo de Emisión Descripción
(chartOptionsChange) Solo Gráficos EventEmitter<ChartOptions> Emite el nuevo objeto de configuración de gráficos cada vez que el usuario realiza cambios en el editor. Habilita [(chartOptions)].
(tableOptionsChange) Solo Tablas EventEmitter<TableOptions> Emite el nuevo objeto de configuración de tablas cada vez que el usuario realiza cambios en el editor. Habilita [(tableOptions)].
(showEditorChange) EventEmitter<boolean> Emite el nuevo estado del editor flotante (true/false) cuando se abre o cierra interactivamente. Habilita [(showEditor)] de forma bidireccional pura.
(seriesChange) Solo Gráficos EventEmitter<Series[]> Emite el conjunto de series generadas y procesadas por el motor cuando cambian los datos o filtros. Ideal para leyendas externas.

Métodos Públicos (API de Componentes)

ChartComponent
  • toPercentage(): void

    Alterna de forma interactiva entre valores absolutos/nominales y cálculo de porcentajes del total.

  • export(type: 'png' | 'jpg' = 'png'): void

    Exporta y descarga el gráfico renderizado como archivo de imagen de alta calidad.

  • toggleShowGoal(goal: Goal): void

    Muestra u oculta de forma dinámica la línea y el área de meta definidos en el modelo Goal.

  • toggleEditor(): void

    Abre o cierra el CDK Overlay del panel de edición de configuraciones visuales.

  • resize(): void

    Fuerza el redimensionamiento del canvas de ECharts para ajustarse al tamaño de su contenedor.

  • getExtremes(): {{ '{' }} start: number; end: number {{ '}' }} | null

    Retorna los límites superior e inferior del navigator del gráfico (si está activo).

TableComponent
  • setValueDisplay(mode: 'nominal' | 'percentOfTotal' | 'percentOfRow' | 'percentOfColumn'): void

    Establece el modo de cálculo matemático para las celdas de la PivotTable en tiempo de ejecución.

  • export(type: 'html' | 'xlsx', name?: string): any

    Exporta los datos calculados a un archivo Excel (.xlsx) estructurado o extrae su marcado HTML nativo.

  • toggleEditor(): void

    Abre o cierra de manera dinámica el panel interactivo CDK Overlay para configurar las columnas y filas de la tabla.

El componente MultipleChartComponent delega la personalización de configuraciones de forma masiva a las directivas de gráficos hijas, por lo que no expone métodos públicos adicionales.
