Uso del componente TableComponent

Esta sección proporciona una guía completa sobre el uso del componente TableComponent para la visualización de datos en formato tabular. Incluye configuraciones disponibles, opciones de personalización y ejemplos prácticos de implementación con capacidades de pivotado y ordenamiento.

Uso del componente TableComponent

El componente TableComponent (con selector de etiqueta <libTable>) se utiliza para mostrar datos en formato tabular con capacidades de pivotado. Requiere un objeto Dataset y un objeto TableOptions como entradas.

Configuración de opciones de la tabla (TableOptions)

TypeScript

Uso en el template HTML

HTML
<libTable [dataset]="dataset" [tableOptions]="tableOptions"></libTable>

Panel de Configuración Interactiva

El componente TableComponent incluye un panel de configuración integrado. Al pasar la propiedad de entrada [showEditor]="showBaseTableEditor" (o llamando al método público toggleEditor()), se mostrará u ocultará de forma dinámica el panel interactivo de pivotado y formato.

  • Pivotado Dinámico: Cambia filas y columnas mediante drag-and-drop.
  • Formato numérico: Ajusta la cantidad de decimales en tiempo real.
  • Totales: Activa o desactiva las filas y columnas de totales.

2. Múltiples Columnas

Esta configuración presenta múltiples columnas ("Sector de gestión" y "Condición") con una sola fila ("Año"). Este diseño es especialmente útil para comparar diferentes categorías lado a lado, permitiendo un análisis transversal de los datos. Los totales por fila y columna facilitan la comprensión de los agregados por cada dimensión, siendo ideal para reportes comparativos entre sectores y condiciones.

3. Ordenamiento Personalizado

Este ejemplo avanzado demuestra cómo implementar ordenamiento personalizado mediante la configuración de sorters. Se define un orden específico para la dimensión "Condición": primero "Nuevo inscripto", luego "Estudiante" y finalmente "Egresado". Esta funcionalidad es crucial para presentar datos educativos en un orden lógico que refleje el flujo académico natural, mejorando significativamente la legibilidad y comprensión de los resultados.

4. Visualización de Porcentajes

Esta funcionalidad permite cambiar dinámicamente entre diferentes modos de visualización de los datos numéricos. Puedes alternar entre valores nominales y distintos tipos de porcentajes: del total general, por fila o por columna. Los botones interactivos utilizan el método setValueDisplay() del componente para transformar la vista de los datos sin recargar la tabla, proporcionando diferentes perspectivas de análisis instantáneamente.
